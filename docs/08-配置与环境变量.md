# 08 — 配置与环境变量

## 环境变量清单

### Supabase

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `VITE_SUPABASE_URL` | Supabase 项目 URL | 前端 + 所有 API |
| `VITE_SUPABASE_ANON_KEY` | Supabase 匿名密钥 | 前端（客户端初始化） |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase 管理员密钥（绕过 RLS） | 所有 API 端 |

### AI 服务 — 记账解析

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `AI_API_URL` | AI API 基础 URL | `parse-transaction`，其他 API 的 fallback |
| `AI_API_KEY` | AI API 密钥 | `parse-transaction` |
| `AI_MODEL` | 模型名称（默认 `deepseek-chat`） | `parse-transaction` |

### AI 服务 — 对话

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `CHAT_AI_API_URL` | 对话 AI URL（优先） | `chat-completion`, `proactive-ai`, `daily-summary` |
| `CHAT_AI_API_KEY` | 对话 AI 密钥（优先） | 同上 |
| `CHAT_AI_MODEL` | 对话模型名称（优先） | 同上 |

> **Fallback 链**：对话类 API 优先使用 `CHAT_AI_*`，未配置时 fallback 到 `AI_*`。前端 `apiConfigs` 可进一步覆盖。

### AI 服务 — Embedding

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `EMBEDDING_API_URL` | Embedding API URL | `vectorize`, `chat-completion`（RAG）, `daily-summary` |
| `EMBEDDING_API_KEY` | Embedding API 密钥 | 同上 |
| `EMBEDDING_MODEL` | Embedding 模型（默认 `text-embedding-3-small`） | 同上 |

> **Fallback 链**：`EMBEDDING_*` → `CHAT_AI_*` → `AI_*`

### Cron 鉴权

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `CRON_SECRET` | Cron 接口 Bearer Token | `proactive-ai`, `daily-summary`, GitHub Actions |

### 用户标识

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `PROACTIVE_USER_ID` | 目标用户 UUID | `proactive-ai`, `daily-summary`, `save-push-token`, `update-location` |

> 默认值：`00000000-0000-0000-0000-000000000000`（硬编码 fallback）

### 华为推送

| 变量 | 用途 |
|------|------|
| `HUAWEI_KEY_ID` | AGC 服务账号 Key ID |
| `HUAWEI_SUB_ACCOUNT` | AGC 子账号 |
| `HUAWEI_PRIVATE_KEY` | Push Kit JWT 私钥（PS256 算法，含 `\n` 换行符） |
| `HUAWEI_PROJECT_ID` | AGC 项目 ID |

### 高德地图

| 变量 | 用途 | 使用位置 |
|------|------|----------|
| `AMAP_API_KEY` | 高德 Web API 密钥 | 逆地理编码（`_context.ts`, `update-location`）、天气（`_weather.ts`） |

### Vercel

| 变量 | 用途 |
|------|------|
| `VERCEL_DOMAIN` | 部署域名（GitHub Actions curl 目标） |
| `MINIMAX_API_KEY` | MiniMax 语音合成 API 密钥（TTS 朗读功能） |

## 项目配置文件

### `package.json`

- **构建脚本**：`build = tsc && vite build`（TypeScript 报错会阻断）
- **依赖**：
  - 前端：`react`, `react-dom`, `react-router-dom`, `zustand`, `react-markdown`, `remark-gfm`, `lucide-react`
  - 后端（`api/`）：`@supabase/supabase-js`, `jsonwebtoken`（仅 proactive-ai 用）
- **开发依赖**：`@vitejs/plugin-react`, `vite`, `typescript`, `tailwindcss`, `@tailwindcss/vite`

### `vite.config.ts`

- React 插件 + TailwindCSS v4 插件
- 开发服务器：`host: '0.0.0.0'`（局域网可访问）
- 构建目标：`esnext`

### `tailwind.config.ts`

马卡龙色系扩展：
```typescript
colors: {
  'base-bg': '#FDFCFB',
  'base-surface': '#F7F5F2',
  'base-text': '#4B5563',
  'base-muted': '#6B7280',
  'base-line': '#E7E5E4',
  'pastel-peach': '#FAD9D2',
  'pastel-mint': '#CFF3E5',
  'pastel-baby': '#D7E8FF',
  'pastel-butter': '#FFF1B8',
  'pastel-lavender': '#E9D9FF',
}
```

### `vercel.json`

- `api/` 目录 → Serverless Functions
- SPA fallback：`src` → `dest: /index.html`

### `tsconfig.json`

- `strict: true`（空值检查等）
- JSX：`react-jsx`
- 路径别名：无

## 前端环境变量（`import.meta.env`）

仅 `VITE_*` 前缀的变量暴露给前端代码：
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

在 `src/supabaseClient.ts` 中初始化 Supabase 客户端。

`.env.local` 文件存储本地开发变量（不提交到 Git）。
