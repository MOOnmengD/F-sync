## 主页 Home (`/`)

**文件**：`src/pages/Home.tsx`（约 979 行）

### 8 种记录模式

通过顶部 PillButton 组切换，状态存储在 `useUi` store 的 `homeMode` 字段；按钮展示顺序与置顶配置存储在 `settings.homeModePreferences`：

| 模式 | `mode` 值 | 输入方式 | 存储目标 | 特有字段 |
|------|-----------|----------|----------|----------|
| 记账 | `finance` | 自由文本 → AI 解析 | `transactions` | `amount`, `finance_category`, `necessity`, `repurchase_index`, `item_id` |
| 点评 | `review` | 自由文本 → AI 解析 | `transactions`（review 字段） | `review`, `item_id` |
| 碎碎念 | `note` | 直接文本 | `transactions`（whisper） | `mood`（emoji 表情） |
| 工作 | `work` | 自由文本 → AI 解析 | `transactions` | 自动关联 Item |
| 收藏 | `save` | 自由文本 → AI 解析 | `transactions` | 自动关联 Item |
| 时间轴 | `timeline` | 计时器（开始/停止/取消） | `transactions`（timing） | `timing_type`, `start_time`, `end_time`, `duration` |
| 理财 | `invest` | InvestmentPanel + OCR 上传 | `investments` | 基金持仓管理、调仓计算、截图识别 |
| 书影 | `media` | 新条目：自由文本 → AI 解析；已有“正在看”条目：直接追加点评 | `media_items` + `media_item_events` | `media_type`, `status`, 多条 `review` / 状态事件 |

默认置顶「记账 / 理财 / 书影」3 个按钮，固定显示在模式栏左侧；其余模式按 `modeOrder` 在右侧单行横向滑动。用户可在 Settings 的「功能按钮顺序」中调整总顺序，并选择最多 3 个置顶按钮。

### 记账/点评流程

1. 用户输入自由文本
2. 前端预处理：`extractDate()` 提取日期、`extractAmount()` 提取金额
3. `POST /api/parse-transaction` — AI 解析为结构化 JSON（`amount`, `item_name`, `brand`, `details`, `review`）
4. 查找或创建 `items` 表记录（按 `item_name` 去重）
5. 写入 `transactions` 表
6. 异步触发 `POST /api/vectorize` 生成 embedding
7. Supabase Realtime 推送 → 其他页面实时更新

### 记账特有功能

- **分类**：衣/食/住/行/其他（PillButton 选择）
- **必要性**：必需/非必需（二选一开关）
- **复购指数**：1-5 级（RepurchaseIndexPill 组件）
- **本月支出汇总**：主页记账模式显示必需支出、总支出、非必需支出；`necessity=false/null` 均归入非必需
- **消费日历**：固定展示当前月，周一开头；四档浅青色表示每日消费强度，未来日期不可点击
- **日期选择**：默认选中今天；正文未写日期时，日历选中日期作为新记账日期；正文显式日期始终优先
- **当天记录**：两列、默认两行高度，只显示 `item_name_snapshot` 和金额；超出后可触摸纵向滚动且隐藏滚动条
- **快捷记录**：按“名称 + 金额 + 点评”统计历史高频消费，满足总计至少 3 次且月均至少 1 次后，最多显示前三个；点击后复制最近模板属性直接写入，不调用 AI
- **补点评提示**：检测上一条记账缺少 review，在分类栏最右侧显示紧凑“补点评”按钮；进入后锁定原交易，不受后续快捷记录影响
- **紧凑属性控件**：必要性与复购指数高度缩小到和分类按钮协调
- **矮屏紧凑布局**：顶部模式区为“置顶按钮固定 + 其余按钮横向滑动”的单行胶囊栏，压缩模式切换、金额汇总、当天记录和底部记账控件的垂直留白；日历方格及主要触摸按钮尺寸保持不变
- **键盘输入态**：移动端输入法弹起或记账输入框聚焦时隐藏主页记账消费面板，只保留模式栏、记账属性按钮和输入框，避免日历/当天记录与固定输入面板叠在一起；输入框聚焦作为 HarmonyOS WebView 未可靠上报 `visualViewport` offset 时的兜底判断
- **悬浮面板辨识度**：顶部模式栏、底部记账属性区和输入框使用页面背景色作为遮挡底色；主页顶部模式栏高于普通内容层级，主页抽屉层级高于顶部模式栏
- **历史日期提示**：“记录到某月某日”显示在输入区域底部，不再额外占用文本框上方高度
- **底部遮挡保护**：通过 `ResizeObserver` 获取固定输入面板实际高度，按快捷按钮换行和日期提示动态保留页面底部滚动空间
- **离线草稿箱**：失败时存入 `localStorage`（key: `fsync_outbox`），可重试

### 记账主页面板数据刷新

- 当前月数据与全部历史快捷统计并行加载，避免快捷统计阻塞汇总和日历
- 历史记账按每页 1000 条分页读取，避免 Supabase 单次返回上限造成统计遗漏
- 监听 `transactions` 的 INSERT / UPDATE / DELETE，使用轻量防抖重新拉取
- 页面重新获得焦点、普通记账成功、快捷记录成功时主动刷新
- 每日消费最小值和最大值完全由前端即时计算，不依赖 GitHub Actions
- 跨过午夜时更新“今天”；若日历仍停留在原默认今天则自动前移，手动选择的本月历史日期保持不变

### 书影连续点评

- 书影输入区域会查询并展示当前 `status='consuming'` 的书籍/影片标题胶囊，按 `updated_at DESC` 排序。
- 点击标题胶囊后自动选中对应类型和“正在看”状态；输入内容全部作为该条目的新点评，不再调用 `/api/parse-media` 拆分标题。
- 发送时通过 Supabase RPC `save_media_record` 原子更新 `media_items` 当前快照，并向 `media_item_events` 写入点评/状态事件。
- 发送成功后取消当前标题选择，避免下一条文本误关联；若状态仍为“正在看”，标题胶囊继续保留。
- 若发送时改为“想看”或“看过”，条目会退出标题胶囊区域；新建为“正在看”的条目会进入该区域。
- `media_items` Realtime 更新及窗口重新获得焦点时会刷新标题胶囊。

### 理财/投资功能

**核心组件**：`InvestmentPanel` → `InvestmentCard`（表格行组件）

**功能概览**：
- **连续表格布局**：外层为单个表格容器，包含表头和行分隔线；列宽已压缩为移动端适配，不再依赖横向滚动。
  - 第一子行：基金名称（>6字截断为前6字+`...`）| 当前持仓（可编辑）| 当前收益率（可编辑）| 调仓建议摘要
  - 第二子行：调仓周期+策略标签 | 建议持仓（可编辑）| 止盈线（可编辑）| 单基金计算按钮
  - 调仓建议列不再与独立计算列争抢宽度；建议金额保持完整显示，单基金计算在建议列下方以独立描边按钮呈现
- **总资产显示**：操作栏最左侧显示所有持仓总市值
- **排序**：按持仓金额/收益率正序倒序、按调仓周期排序
- **公式展示与编辑**：表格上方展示补仓和止盈公式，使用「当前持仓 / 目标持仓 / 收益率 / 止盈线」中文变量；可编辑阈值、比例、金额上限，配置保存在 `localStorage`（key: `fsync.investment.formula.v1`）。再平衡规则已移除，不会因为单纯低配/超配产生大额调仓建议
- **补仓金额上限**：买入建议只由补仓规则产生，默认按 `min((目标持仓 - 当前持仓) × 20%, 500元)` 计算，单只基金单次建议不超过 500 元
- **本地草稿编辑**：点击持仓、收益率、建议持仓、止盈线数值进入编辑态；输入框使用完整列宽，下方显示整宽「确定」按钮，确认后写入本地草稿并立即影响调仓计算，点击数字区域外取消本次输入
- **总保存按钮**：操作栏提供「保存 N」按钮，将现有基金修改和截图新增基金的本地草稿通过 `/api/investment` 的 `type=batch_update` 一次性同步到 Supabase
- **批量计算**：一键为所有基金计算调仓建议，计算基于当前本地草稿数据和本地公式配置，不依赖已同步到 Supabase
- **单基金计算**：每行建议列下方保留独立「单独计算」按钮，和可点击的建议金额区域以边框及上下层级区分
- **操作确认**：有买入/卖出建议时，点击整块建议金额区域进入编辑态，输入框默认带入建议金额；点击下方整宽「确定」按钮按当前金额确认并写入 `investment_actions`，点击区域外取消，不再使用狭小的「确认/改额」文字按钮
- **OCR 截图识别**：上传养基宝/支付宝持仓截图，通过视觉模型自动识别，匹配后先套入本地草稿，点击总保存后同步；模型 API 与 Prompt 可在 Settings 的「理财截图解析」卡片配置
  - 上传控件支持一次选择多张图片，前端逐张压缩和识别，最后按匹配到的基金 ID / 标准化基金名去重合并
  - 识别时会同时读取第三列「持有收益率」和第四列「关联板块」涨跌幅；API 返回的 `profit_rate` 为两列相加后的真实收益率，第四列缺失或为空时保持第三列原值
  - 名称匹配前会忽略空白、中文/英文圆括号、截断省略号及常见中英文逗号/句号；只移除括号符号，保留括号内文字，避免丢失基金名称中的有效标识
  - 数据库中没有的基金会显示为「待新增」，默认采用 OCR 名称，并允许在应用前手动补全名称、持仓金额和收益率；取消勾选可忽略该条目
  - 新基金应用后先以「待保存」行进入本地持仓，可继续修改参数或点击「取消新增」撤回；默认目标持仓等于当前持仓、调仓周期为「无」、策略标签为「待配置」；保存前不会写入 Supabase，也不参与调仓建议计算
  - 同一完整名称在重叠截图中重复出现时仅覆盖非空识别值，不重复累加；名称主体完全相同且末尾是两个或更多不同 A/C/E 份额类别时，合并持仓金额，并按各份额持仓成本计算合并收益率
  - 如果合并组分别匹配到数据库中的多只基金，结果弹窗要求用户选择更新目标；未选择时本次忽略该合并项，不会静默覆盖
  - 图片会经 `compressImage()` 压缩：每张原图需小于 5MB，最长边超过 1536px 会等比缩小并转为 WebP 0.75；多张普通截图通常比一张特别长的长截图更清晰
- **持仓管理**：InvestManageModal 弹窗进行基金的增删改

## AI 对话 Chat (`/chat`)

**文件**：`src/pages/Chat.tsx`（约 1900+ 行）

### 核心功能

1. **消息列表**：Markdown 渲染（`react-markdown` + `remark-gfm`），时间戳显示
2. **消息发送**：文本 + 图片（base64 压缩），支持直传多模态或独立识图转文字
3. **语音朗读**：AI 消息气泡下方有朗读按钮（调用 `/api/text-to-speech`）；Header 右侧有自动朗读开关，开启后 AI 新消息自动播放
4. **设置面板**：SettingsModal — 编辑 system prompt、user prompt、post-history prompt、apiConfigs、聊天图片理解模式
5. **日记查看**：ProfileDiaryModal — 查看 AI 生成的每日日记和用户画像（个人事实 + 社交关系，均可编辑）
6. **上下文查看**：ContextViewerModal — 查看发送给 AI 的完整上下文，支持一键导出（复制到剪贴板）
7. **消息删除**：二次确认删除（本地 + Supabase 级联）
8. **向量同步**：手动触发向量化同步
9. **快速记录**：QuickRecordButtonBar + QuickRecordPopup（在聊天中快速记账）

### 技术细节

- **位置获取**：通过 HarmonyOS 原生桥接 `harmonyBridge.requestLocation()`，5 分钟缓存
- **Token 估算**：中文字符 ≈ 1.5 token/字，英文字符 ≈ 4 字符/token，图片 ≈ 85 token
- **聊天图片理解**：
  - `direct`：图片以 `image_url` parts 直传给主聊天模型，适合原生多模态模型
  - `vision_summary`：先调用独立视觉模型生成图片摘要，再把纯文本摘要交给主聊天模型，适合 GLM-5.2 等文本模型
  - 新生成的图片摘要会写回本地消息 `imageSummary`，后续追问同一张图片时只发送摘要，不再重复识图
- **性能优化**：React.memo + useCallback 防止消息重渲染；Markdown 组件提取为模块级常量
- **设置云端同步**：打开设置面板自动 `loadFromCloud()`，保存自动 `saveToCloud()`

## 设置 Settings (`/settings`)

**文件**：`src/pages/Settings.tsx`

- **入口**：DrawerNav 中的「设置 Settings」
- **页头退出**：左侧 `IconButton`（`ArrowLeft`）返回主页 `/`
- **云端同步状态**：页面挂载时自动调用 `loadFromCloud()`；设置尚未加载完成时，页头右侧显示「同步中…」徽标，并在正文展示加载提示；云端无记录或查询失败时也会结束加载态，避免长期卡在同步提示
- **顶层折叠入口**：页面标题为「设置」，包含「功能按钮顺序」和「AI 设置」两个顶层折叠区
- **功能按钮顺序**：展示 8 个主页模式，可用图钉选择最多 3 个置顶按钮，并用上移/下移按钮调整 `modeOrder`（桌面端也可拖拽）；保存后同步到 `user_settings.settings.homeModePreferences`
- **AI 设置**：展开后展示文本解析、图像解析、语音合成、对话模型等配置
- **文本解析配置**：记账解析、影音解析两个折叠卡片，支持 API URL / API Key / 模型 / Prompt 编辑与保存
- **解析配置复用**：「影音解析」未单独填写 URL/Key/模型时，主页书影新增会复用「记账解析」的 URL/Key/模型，Prompt 仍使用影音解析配置或默认影音 Prompt
- **图像解析配置**：理财截图解析折叠卡片，支持视觉模型 API URL / API Key / 模型 / Prompt 编辑与保存；Prompt 留空时使用默认养基宝持仓截图提示词
- **语音合成配置**：TTS 折叠卡片，支持 MiniMax 端点、Key、模型、音色、语速配置
- **移动端 Key 输入**：API Key 输入框始终使用普通文本输入类型，避免 HarmonyOS WebView 拉起无法复制粘贴的安全键盘；未编辑时以掩码展示，并提供显示/隐藏、粘贴、复制按钮
- **对话模型摘要**：展示 Chat 页面当前启用 API 数量和模型摘要，并提供跳转到 Chat 设置的入口
- **聊天图片摘要**：展示 Chat 当前图片理解模式（直传主模型 / 识图转文字）和识图模型名；完整配置仍在 Chat 设置面板中维护

## 书影清单 Library (`/library`)

**文件**：`src/pages/Library.tsx`

- **数据源**：Supabase `media_items` 表（当前快照）+ `media_item_events`（多条点评与状态历史）
- **类型筛选**：全部 / 书籍 / 影片（PillButton 切换）
- **状态筛选**：全部 / 想看 / 正在看 / 看过（PillButton 切换）
- **排序**：正在看 → 想看 → 看过（同状态按创建时间倒序）
- **添加条目**：已迁移至主页「书影」模式（自由文本输入 → AI 解析标题+评价 → `save_media_record` RPC）
- **编辑条目**：卡片右侧编辑按钮 → 弹出表单，可修改标题、类型、状态；状态变化会写入历史事件
- **点评展示**：卡片展示 `media_items.review` 中的最近一次点评；编辑弹窗不再覆盖点评，历史点评编辑留给后续书影时间轴
- **删除条目**：卡片右侧删除按钮 → 二次确认后删除
- **空状态**：无数据时显示引导文案
- **错误处理**：请求失败时显示错误提示 + 重试按钮
