## 主页 Home (`/`)

**文件**：`src/pages/Home.tsx`（约 979 行）

### 6 种记录模式

通过顶部 PillButton 组切换，状态存储在 `useUi` store 的 `homeMode` 字段：

| 模式 | `mode` 值 | 输入方式 | 存储 type | 特有字段 |
|------|-----------|----------|-----------|----------|
| 记账 | `finance` | 自由文本 → AI 解析 | `记账` | `amount`, `finance_category`, `necessity`, `repurchase_index`, `item_id` |
| 点评 | `review` | 自由文本 → AI 解析 | `记账`（review 字段） | `review`, `item_id` |
| 碎碎念 | `note` | 直接文本 | `whisper` | `mood`（emoji 表情） |
| 工作 | `work` | 自由文本 → AI 解析 | 记账格式 | 自动关联 Item |
| 收藏 | `save` | 自由文本 → AI 解析 | 记账格式 | 自动关联 Item |
| 时间轴 | `timeline` | 计时器（开始/停止/取消） | `timing` | `timing_type`, `start_time`, `end_time`, `duration` |

### 记账/点评流程

1. 用户输入自由文本
2. 前端预处理：`extractDate()` 提取日期、`extractAmount()` 提取金额
3. `POST /api/parse-transaction` — AI 解析为结构化 JSON（`amount`, `item_name`, `brand`, `details`, `review`）
4. 查找或创建 `items` 表记录（按 `item_name` 去重）
5. 写入 `transactions` 表
6. 异步触发 `POST /api/vectorize` 生成 embedding
7. Supabase Realtime 推送 → 其他页面实时更新

### 记账特有功能

- **分类**：衣/食/住/行/娱乐（PillButton 选择）
- **必要性**：必需/非必需（二选一开关）
- **复购指数**：1-5 级（RepurchaseIndexPill 组件）
- **补点评提示**：检测上一条记账缺少 review，显示提示卡片，点击后进入补点评模式
- **离线草稿箱**：失败时存入 `localStorage`（key: `fsync_outbox`），可重试

### 碎碎念特有功能

- **心情 emoji**：预设 5 个（😐🥰😔🤬😖），支持自定义 emoji 添加
- **直接写入**：无需 AI 解析，直接写入 `transactions` 表 `type='whisper'`

### 时间轴/计时功能

- 使用 `useTimeline` hook，通过 `localStorage`（key: `fsync.timeline.active.v1`）持久化进行中的计时
- 4 种计时类型：睡眠/生活/工作/娱乐
- 支持切换类型（自动结算上一段并开始新计时）
- 实时显示计时时长（每秒刷新）
- 停止时写入 `transactions` 表（`type='timing'`）
- 页面展示 `WeeklyTimeline` 组件（周时间轴视图）

### UI 细节

- 键盘弹起时自动调整输入框位置（监听 `visualViewport`）
- Toast 提示（1.2 秒自动消失）
- 自定义 emoji 对话框（Modal 遮罩）

## AI 对话 Chat (`/chat`)

**文件**：`src/pages/Chat.tsx`（约 1900+ 行）

### 核心功能

1. **消息列表**：Markdown 渲染（`react-markdown` + `remark-gfm`），时间戳显示
2. **消息发送**：文本 + 图片（base64 压缩），支持多模态
3. **设置面板**：SettingsModal — 编辑 system prompt、user prompt、post-history prompt、apiConfigs
4. **日记查看**：ProfileDiaryModal — 查看 AI 生成的每日日记和用户画像
5. **上下文查看**：ContextViewerModal — 查看发送给 AI 的完整上下文，支持一键导出（复制到剪贴板）
6. **消息删除**：二次确认删除（本地 + Supabase 级联）
7. **向量同步**：手动触发向量化同步
8. **快速记录**：QuickRecordButtonBar + QuickRecordPopup（在聊天中快速记账）

### 技术细节

- **位置获取**：通过 HarmonyOS 原生桥接 `harmonyBridge.requestLocation()`，5 分钟缓存
- **Token 估算**：中文字符 ≈ 1.5 token/字，英文字符 ≈ 4 字符/token，图片 ≈ 85 token
- **性能优化**：React.memo + useCallback 防止消息重渲染；Markdown 组件提取为模块级常量
- **设置云端同步**：打开设置面板自动 `loadFromCloud()`，保存自动 `saveToCloud()`

### 组件拆分

| 组件 | 说明 |
|------|------|
| `WelcomeBubble` | 首次进入的欢迎消息 |
| `MarkdownContent` | Markdown 渲染包装 |
| `SettingsModal` | 设置面板（含 API 配置管理） |
| `ContextViewerModal` | 全量上下文查看器 |
| `ProfileDiaryModal` | AI 日记 + 用户画像查看 |
| `QuickRecordButtonBar` | 快速记录模式选择按钮组 |
| `QuickRecordPopup` | 快速记录弹出输入框 |

## 记账报表 Finance (`/finance`)

**文件**：`src/pages/Finance.tsx`

- **数据源**：Supabase `transactions` 表 `type='记账'`
- **月选择器**：MonthPicker 组件，可按月切换
- **按天分组**：同一天记录分组展示，支持收起/展开
- **金额汇总**：每天合计 + 每月合计
- **Item 名称展示**：批量查询 `items` 表获取 item_name
- **Realtime 更新**：监听 `transactions` 表的 INSERT/UPDATE
- **无网络降级**：显示错误提示
