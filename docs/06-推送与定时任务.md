# 06 — 推送通知与定时任务

## 概述

主动消息通过两层调度实现：
1. **GitHub Actions** 定时触发（cron）
2. **Vercel Serverless Function** 执行 AI 决策 + 推送

---

## GitHub Actions 定时任务

### `proactive-ai-pulse.yml` — 主动消息脉冲

| 属性 | 值 |
|------|-----|
| 调度 | 每 15 分钟（`*/15 * * * *`） |
| 手动触发 | 支持（`workflow_dispatch`） |
| 调用端点 | `POST https://<VERCEL_DOMAIN>/api/proactive-ai` |
| 鉴权 | `Authorization: Bearer <CRON_SECRET>` |

**静默时段**：CST 01:00-10:00 不触发（在 workflow 层面判断，避免打扰用户休息）

```bash
CST_HOUR=$(TZ='Asia/Shanghai' date +%H | sed 's/^0//')
if [ "$CST_HOUR" -ge 1 ] && [ "$CST_HOUR" -lt 10 ]; then
  exit 0  # 跳过
fi
```

### `daily-summary.yml` — 每日摘要

| 属性 | 值 |
|------|-----|
| 调度 | 每天 UTC 17:00（CST 次日 01:00） |
| 手动触发 | 支持（`workflow_dispatch`） |
| 调用端点 | `POST https://<VERCEL_DOMAIN>/api/daily-summary` |
| 鉴权 | `Authorization: Bearer <CRON_SECRET>` |

## 华为 Push Kit 集成

### 推送链路

```
POST /api/proactive-ai
  → AI 决策发送 → 写入 chat_messages（client_id=proactive-{timestamp}）
  → Supabase Realtime 推送到前端
  → 前端检测 client_id 以 proactive- 开头
  → 调用 harmonyNative.receiveMessage() → 系统通知 + 振动

同时：
  → sendHuaweiPush() → 华为 Push Kit v3 API
  → 推送通知到设备（即使应用在后台）
```

### Push Kit 配置

| 参数 | 环境变量 |
|------|----------|
| 密钥 ID | `HUAWEI_KEY_ID` |
| 子账号 | `HUAWEI_SUB_ACCOUNT` |
| 私钥 | `HUAWEI_PRIVATE_KEY`（PS256 算法） |
| 项目 ID | `HUAWEI_PROJECT_ID` |

### JWT 认证流程

```
HUAWEI_PRIVATE_KEY (PS256) → JWT Token → POST oauth-login.cloud.huawei.com/oauth2/v3/token
  → access_token → POST push-api.cloud.huawei.com/v3/{projectId}/messages:send
```

### 推送消息结构

```json
{
  "payload": {
    "notification": {
      "category": "IM",
      "title": "弗弗",
      "body": "AI 生成的消息内容",
      "clickAction": { "actionType": 0 }
    }
  },
  "target": {
    "token": ["device_push_token"]
  }
}
```

- **category: IM**：即时通讯分类（已申请 IM 自分类权益），支持后台横幅通知
- **actionType: 0**：点击通知打开应用

### Push Token 存储

- 存储表：`push_tokens`
- 保存接口：`POST /api/save-push-token`
- 唯一约束：`(user_id, platform)`
- 由 HarmonyOS 端在获取到 Push Token 后调用

## 前端主动消息处理 (`App.tsx`)

```typescript
// 监听 Supabase Realtime INSERT 事件
supabase.channel('harmony-proactive-notif')
  .on('postgres_changes', 
    { event: 'INSERT', schema: 'public', table: 'chat_messages' },
    (payload) => {
      if (msg.client_id?.startsWith('proactive-') && msg.content) {
        harmonyNative.receiveMessage(JSON.stringify({
          type: 'showNotification',
          data: { title: '弗弗', content: msg.content }
        }))
      }
    }
  )
```

- 检测 `client_id` 以 `proactive-` 前缀标识主动消息
- 通过 HarmonyOS 原生桥接触发通知

## proactive-ai 详细流程

1. **鉴权**：验证 `CRON_SECRET`
2. **位置获取**：从 `user_locations` 表读取最新位置
3. **对话检查**：查询最近 30 条消息 → 如果 1 小时内有对话则 SKIP（`force=true` 可跳过此检查）
4. **数据收集**：
   - 最近 12 小时生活记录（transactions，limit 10）
   - 最近对话（chat_messages，limit 30）
5. **上下文构建**：调用 `enrichMessages()`（与 chat-completion 共享管线）
6. **AI 决策**：
   - 注入 proactivePrompt 作为 user 消息
   - AI 回复文本或 `SKIP`
7. **写入 + 推送**：
   - AI 决定发送 → 写入 `chat_messages` → `sendHuaweiPush()`
   - 等待推送完成再返回（Vercel 环境在 return 后会终止异步任务）
8. **画像更新**：异步（不阻塞主流程）调用 `updateUserProfileSummary()`
