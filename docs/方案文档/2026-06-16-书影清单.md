## 功能名称

**书影清单** — 记录看过的书籍/影片，追踪想看的内容，管理阅读/观看状态。

---

## 背景与动机

用户希望有一个独立的空间来记录和管理自己看过的书籍和影片。当前 F-Sync 的「点评」和「收藏」功能都是围绕消费/物品场景（买了什么、好不好用），与书籍/影片的文化消费场景不同：

- 书籍/影片有**状态生命周期**：想看 → 正在看 → 看过
- 不涉及金额、必要性、复购等消费属性
- 需要按类型（书/影）、状态筛选浏览

因此最初作为独立功能开发，随后将「添加条目」操作迁移至主页「书影」模式，复用记账模式的交互范式（自由文本输入 → AI 解析），Library 页面专注浏览和管理。

---

## 设计目标

- [ ] 用户可添加书籍或影片条目（标题、类型）
- [ ] 每个条目支持三种状态：想看 / 正在看 / 看过
- [ ] 用户可为条目写点评/笔记
- [ ] 支持按类型（书/影）和状态筛选
- [ ] 独立页面展示，不干扰现有功能
- [ ] 保持与现有设计风格一致（马卡龙色系、极简）

## 设计方案

### 数据流

```
用户在 /library 页面
  ├── 查看列表 ← Supabase SELECT（直接查询，带筛选条件）
  ├── 添加条目 → Supabase INSERT → 列表刷新
  ├── 修改状态/点评 → Supabase UPDATE → 列表刷新
  └── 删除条目 → 二次确认 → Supabase DELETE → 列表刷新
```

不经过 API 端点，前端直接使用 Supabase 客户端操作（与 Finance / Whisper 页面一致）。

### 数据库变更

```sql
-- 迁移文件：migrations/016_media_items.sql

CREATE TABLE media_items (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID NOT NULL REFERENCES auth.users(id),
  title       TEXT NOT NULL,                          -- 书名/影名
  media_type  TEXT NOT NULL CHECK (media_type IN ('book', 'movie')),  -- 书籍/影片
  status      TEXT NOT NULL DEFAULT 'want_to_consume'
              CHECK (status IN ('want_to_consume', 'consuming', 'consumed')),
  review      TEXT,                                   -- 用户点评/笔记
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 索引：按用户 + 类型 + 状态快速筛选
CREATE INDEX idx_media_items_user_type_status ON media_items (user_id, media_type, status);
CREATE INDEX idx_media_items_user_created ON media_items (user_id, created_at DESC);

-- RLS
ALTER TABLE media_items ENABLE ROW LEVEL SECURITY;
CREATE POLICY media_items_user_policy ON media_items
  FOR ALL USING (auth.uid() = user_id);

-- 自动更新 updated_at
CREATE OR REPLACE FUNCTION update_media_items_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER media_items_updated_at
  BEFORE UPDATE ON media_items
  FOR EACH ROW EXECUTE FUNCTION update_media_items_updated_at();
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | UUID | 主键 |
| `user_id` | UUID | 所属用户 |
| `title` | TEXT | 书名或影片名（必填） |
| `media_type` | TEXT | `book` = 书籍，`movie` = 影片 |
| `status` | TEXT | `want_to_consume` = 想看，`consuming` = 正在看，`consumed` = 看过 |
| `review` | TEXT | 个人点评/笔记（可选） |
| `created_at` | TIMESTAMPTZ | 条目创建时间 |
| `updated_at` | TIMESTAMPTZ | 最后修改时间 |

## 边缘情况

- [x] **加载中状态**：首次加载时显示 loading 骨架/文字
- [x] **空数据状态**：无条目时显示引导文案（如「还没有记录，点击下方按钮添加第一本书或影片吧」）
- [x] **空筛选结果**：当前筛选条件无匹配时显示「没有符合条件的条目」
- [x] **错误处理**：Supabase 请求失败时显示错误提示 + 重试按钮
- [x] **超长标题**：标题过长时截断显示（CSS `truncate`），完整标题在详情/编辑中可见
- [x] **超长点评**：卡片中点评默认显示 3 行，超出折叠
- [x] **删除确认**：点击删除后弹出二次确认，防止误删
- [x] **未登录**：页面受 App.tsx 的全局认证守卫保护，无需额外处理
- [x] **网络离线**：显示错误提示，数据为空时不误显示「暂无数据」
