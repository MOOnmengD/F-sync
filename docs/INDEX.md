## 📝 文档规范

### 新增功能流程

1. **设计阶段**：复制 `方案文档/TEMPLATE.md`，在 `方案文档/` 目录创建 Markdown 文件，命名格式 `YYYY-MM-DD-功能名.md`。设计文档需经用户确认后再开始实现。
2. **实现阶段**：按设计文档编码，编码前先阅读相关的 `0X-*.md` 说明文档。
3. **归档阶段**：实现完成后更新对应的 `0X-*.md` 说明文档，保持文档与代码同步。

### 文档编写原则

- **结构化**：使用清晰的标题层级
- **可追溯**：记录关键设计决策及其原因
- **面向 AI**：包含足够的上下文让 AI 能理解项目，避免幻觉
- **与代码同步**：代码变更时同步更新文档
