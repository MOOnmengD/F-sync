# 01 — 项目概览

## 项目定位

F-Sync 是一个**个人生活记录 + AI 生活助手** Web 应用，部署于 `https://www.fsync.top`。单一用户使用（开发者本人），通过 HarmonyOS WebAbility 封装为移动端应用（类 PWA 体验）。

**核心理念**：以 AI 恋人 "Florian（弗弗）" 的角色，通过访问用户的生活轨迹数据，参与和陪伴用户的日常生活。

## 设计规范

- **配色**：马卡龙色系（peach/mint/baby/butter/lavender），定义在 `tailwind.config.ts`
- **风格**：极简、无阴影（全局 `box-shadow: none !important`）
- **圆角**：统一使用 `rounded-2xl`
- **背景色**：`#FDFCFB`（base-bg）/ `#F7F5F2`（base-surface）
- **文字色**：`#4B5563`（base-text）/ `#6B7280`（base-muted）
- **边框色**：`#E7E5E4`（base-line）
- **移动端适配**：最大宽度 480px，居中布局，底部 safe-area 适配
